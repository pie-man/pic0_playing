## Small python scripts for use on a Raspberry Pico board.

Mainly concentrating on a Pico 2W with either a Pimoroni display Pack 2 or display pack 2.8 attached.
These then have environmental sensors attached via the qw/st port
There is also an intention to add further 1 wire sensors such as the DS18B20 to be able to measure and plot temperatures in multiple locations at once.
